# Smart Home Device Hierarchy Manager

## Project Overview
The Smart Home Device Hierarchy Manager is a Python application that organizes smart home rooms and devices using a General Tree data structure. It provides a graphical user interface developed using Tkinter.

## Objectives
- Represent the smart home using a General Tree.
- Organize rooms and devices hierarchically.
- Add, search, and delete rooms or devices.
- Toggle device power status.
- Display tree traversal results and statistics.

## Technologies Used
- Python
- Tkinter
- General Tree Data Structure
- Depth-First Search (DFS)
- Breadth-First Search (BFS)

## Data Structures and Algorithms
- **General Tree:** Represents the Smart Home Hub, rooms, and devices.
- **DFS:** Preorder and Postorder traversals.
- **BFS:** Level-order traversal using a queue.

## How to Run
1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the application using:

```bash
python smart_home.py
```

Replace `smart_home.py` with the actual Python filename if it is different.

## Project Scope
This is an educational software prototype. Device power status is managed within the application; physical IoT device connectivity is not included unless implemented separately.
